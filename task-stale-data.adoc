= NetApp Data Classificationで古いデータ定義をカスタマイズする
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification は、古いデータを特定することで、コスト削減の機会を見つけ出し、データ ガバナンス上のリスクに対処できます。組織のニーズに合わせて古いデータの定義をカスタマイズし、最終アクセス日時または最終更新日時に基づいて古いデータを特定します。

古いデータは、最後にアクセスされた日時または最後に変更された日時に基づいて定義できます。期間は6ヶ月から10年まで選択できます。

デフォルトでは、データが最後に変更されてから 3 年前であれば古いデータとみなされます。

.古いデータを定義する
. データ分類で、**構成** を選択します。
. 設定ページで、*Settings*タブを選択します。
. 「古いデータ定義」の見出しの下にある*編集*を選択します。
. **ファイルプロパティ**ドロップダウンメニューで、古いデータを定義する基準を*最終アクセス日時*または*最終更新日時*のどちらにするかを選択します。
. 古いデータ定義の期間を選択します。
. **保存**を選択します。
